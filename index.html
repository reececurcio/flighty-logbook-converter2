What it calculates

Total Time: actual gate departure to actual gate arrival, converted through UTC using each airport's time zone.

Night Time: estimated airborne time occurring after the selected sunset offset and before sunrise, sampled along the route.

Landings: one day or night landing for each completed flight with an actual landing timestamp.

Airport coordinates and IANA time zones are bundled with the app. Local airport timestamps are converted to UTC using the iPhone’s built-in time-zone engine before block time is calculated.
